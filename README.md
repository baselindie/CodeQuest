# CodeQuest

CodeQuest es una plataforma gratuita y gamificada para aprender HTML, CSS, JavaScript e inglés técnico mediante misiones, proyectos, logros y progreso sincronizado.

## Características

- 131 misiones organizadas en cuatro mapas.
- Retos prácticos con validación para reducir el copiar y pegar.
- Proyectos, recompensas, logros, rachas y mascotas.
- Progreso local y sincronización mediante Supabase.
- PWA instalable y diseño responsive.
- Certificados de finalización verificables.

## Tecnologías

- Next.js / Vinext
- TypeScript y JavaScript
- HTML y CSS
- Supabase Auth, Database y Edge Functions
- PWA y Service Worker

## Desarrollo local

```bash
npm install
npm run dev
```

Las credenciales y claves deben configurarse mediante variables de entorno. Los archivos `.env*` están excluidos del repositorio.
